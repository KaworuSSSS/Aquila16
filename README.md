# Aquila16

Proyecto de diseño de una computadora de 16 bits basada en FPGA.

## Objetivo

Crear una CPU propia en VHDL y un ecosistema completo:

- Procesador Aquila-16
- Ensamblador en Python
- Cargador de programas
- Periféricos FPGA
- Herramientas de depuración

## Hardware objetivo

FPGA:
- Altera Cyclone IV
- EP4CE6E22C8N

Frecuencia:
- 50 MHz

## Lenguajes

Hardware:
- VHDL

Software:
- Python
